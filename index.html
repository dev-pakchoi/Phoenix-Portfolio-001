My Boids simulation

A real-time Boid flocking simulation built with p5.js, inspired by the collective behaviour of birds and other flocking animals.Each Boid uses three core behaviours — separation, alignment, and cohesion — to create natural-looking flock movement.

To improve performance, I implemented a quadtree spatial partitioning algorithm for efficient neighbour detection, reducing the complexity from O(N²) to O(N log N).This optimisation allowed the simulation to handle around ~1,000 Boids simultaneously while maintaining smooth real-time performance.
